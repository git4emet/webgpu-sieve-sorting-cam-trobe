## Workload modules

### Particle simulation
- N-body particle update.
- WGSL compute shader programming.
- Boundary collision handling.
- Instanced rendering.
- CPU/GPU workload comparison.
- Runtime FPS measurement.

### Matrix multiplication
- Tiled matrix multiplication.
- 16×16 WGSL workgroup design.
- Shared-memory use.

- Execution-time measurement and repeated-run averages.

- Separable Gaussian blur.
- Sobel X/Y edge detection and gradient magnitude.
- Thresholding.
- Multi-pass GPU compute.
- Ping-pong texture handling.
- CPU/GPU comparison.
